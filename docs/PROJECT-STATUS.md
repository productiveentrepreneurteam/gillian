# Gillian site project

Review snapshot, 2026-10-15. Prepared by Larry with Iris directing the design.

## Available source

The repository contains real homepage HTML, CSS, navigation and motion scripts,
selected photographs, actual wordmarks, publication logos and open-license fonts.
`index.html` and `homepage.html` are the same page; no build step is required.
`source-manifest.json` records the runtime file hashes.

Commercial Eugenio font binaries, private source documents, invoices, reference
screenshots and credentials are excluded. The public draft uses a fallback
display face, so it is not an exact typography preview.

## Current direction

- Navigation overlays the cover in white, then becomes a white masthead with a
  black logo and thin bottom rule. Destinations: Home, About, Our Work, Contact.
- Actual publication marks sit on a generously padded cream strip.
- The introduction leads directly into The Editorial Treatment. Process C uses
  a readable 01-02-03 story beside a layered, numbered photographic collage.
- Intended type: Eugenio Light headings, Light Italic quote, Bold step numerals,
  Baskervville body copy and upright Archivo eyebrows/buttons.
- The photographic quote uses a narrow white panel and oversized centered marks.
  The footer repeats navigation and gives brokerage logos more space.
- Motion reveals selected elements once, honors reduced motion and leaves content
  available without scripts.

## Integration status

This review lives on `codex/gillian-handoff-2026-10-15`. Leave `main` unchanged
until the target project and website code-sync behavior are confirmed. A general
GitHub authorization is not proof of a connected Manus website.

The original Manus project uses React/Vite. Adapt this source within that existing
structure, preserving routes, other pages and integrations. The HTML is a source
reference; automatic import has not been verified.

[Squarespace research](SQUARESPACE-RESEARCH.md) evaluates an alternative route.
No Squarespace connector has been installed or tested, and no migration has run.
There is no final platform-change decision in this snapshot.
