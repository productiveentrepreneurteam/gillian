## Website Files

Open `index.html` to view the static homepage. `homepage.html` contains the same
page for the existing preview URL. Both use `homepage.css`, `nav.js`, `motion.js`
and the selected assets in `assets/`. No build step is required.

This public repository excludes the commercial Eugenio font files, private
documents and Canva screenshots. The public draft uses a fallback display face.
Supply the licensed Eugenio Light, Light Italic and Bold files privately after
checking web-use rights. Reuse existing private copies if present in the target
project. Do not put those commercial files into this public repository.

## Instructions For Manus

Use the actual HTML, CSS, scripts and assets from this repository to adapt the
homepage in Gillian's existing project. Preserve the supplied copy, photo choices,
layout, responsive behavior, publication strip and continuous numbered process.
Use the existing framework and routes. Keep other pages and integrations intact.
Return an unpublished desktop/mobile preview. Do not publish or change client data.

Reuse Archivo for all centered, upright eyebrows; Baskervville for body copy;
licensed Eugenio Light for display text, Light Italic for the pull quote and Bold
for the process numerals. Reuse the project's icon system where appropriate.

Before approval, review font loading, text wrapping, quote marks, mobile collage
overlap, keyboard navigation and contact destinations. Tracking is zero in this
source and remains an unresolved design detail. The draft About and contact
destinations need integration with the existing site's intended routes.

The source and motion checks passed locally. Fresh visual verification remains
pending. `source-manifest.json` identifies the runtime files with SHA-256 hashes.

This repository is a source handoff, not a published website. The website-level
Manus connection has not been verified. Manus documents website sync for
repositories created through its own export flow; importing this existing
repository in one click has not been verified. Do not merge the review branch
until the actual target and sync behavior are confirmed.
